Recién graduado en **Informática y Computación**, apasionado por el desarrollo de software y la resolución creativa de problemas. Cuento con experiencia destacada en el diseño y desarrollo de proyectos académicos utilizando **Java Spring Boot** y **arquitectura de microservicios**.

Actualmente busco oportunidades donde pueda aplicar y ampliar mis habilidades, aportando soluciones eficientes e innovadoras a proyectos de desarrollo de software.

- 🌱 Profundizando en **arquitectura de microservicios** y buenas prácticas de API REST
- 👯 Abierto a colaborar en proyectos open source
